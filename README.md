# AeroBot - Silkroad Online Advanced Bot 🚀

بوت متطور للعبة **Silkroad Online (vSRO / iSRO / Private Servers)** مبني على .NET بتقنيات حديثة وواجهة مستخدم احترافية بالكامل باللغة العربية والإنجليزية.

---

## ✨ المميزات الرئيسية (Features)

- 🐪 **نظام التجارة التلقائي (Automatic Trade System)**:
  - دعم نقل البضائع الآلي والرحلات بين المدن (Jangan <-> Hotan).
  - ركوب جمل التجارة وتحميل وشراء البضائع وبيعها تلقائياً.
  - مسارات متعددة (Route Lists) مع دعم التتبع الآلي وتخطي العقبات.

- 📜 **صانع السكربتات المتقدم (Script Creator - phBot Style)**:
  - 42 زر تفاعلي مطابق تماماً لـ phBot لأوامر المدينة، الحركة، والتجارة.
  - محرر أكواد داكن (Dark Code Editor) مع ترقيم الأسطر وتتبع الحالة المباشرة.
  - تسجيل حي وتحرير فوري للأوامر.

- ⚔️ **المهام المستقلة (Quests)**:
  - تبويب مستقل للمهام يتيح متابعة وإلغاء المهام وعرض الجوائز بدقة.
  - دعم أمر السكربت `quest` للتفاعل الآلي مع الـ NPCs.

- 🧩 **مدير الإضافات السريع (Plugin Manager)**:
  - تثبيت أي إضافة (`.dll`) بضغطة زر واحدة وتحميلها فورياً بدون إعادة تشغيل.
  - فتح مجلد الإضافات بنقرة واحدة من القائمة العلوية.

- 🎨 **واجهة عصرية (Modern UI & Dark Mode)**:
  - تصميم متناسق ومريح للعين يدعم الوضع الليلي بالكامل.
  - تعريب شامل ودقيق لجميع القوائم والأزرار.

## 🛠️ البناء من المصدر (Build from Source)

- **المتطلبات**: .NET 6.0 SDK أو أحدث.
- **أمر البناء**:
  ```bash
  dotnet build RSBot.sln
  ```
- المخرجات ستكون جاهزة في مجلد `Build/`، شغل `AeroBot.exe`.
